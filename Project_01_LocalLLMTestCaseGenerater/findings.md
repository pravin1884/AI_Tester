# Findings

## Research
- Design mockups analyzed (`LocalLLMTestCaseDesign.png`):
  - **Main Window**: Sidebar for "History", main output area for generated test cases, and an input box for requirements.
  - **Settings Window**: Configuration fields for "Ollama Setting", "Groq Setting", "Open AI API keys", "Save Button", and "Test Connection".

## Discoveries
- **Target Domain**: API and Web Application test cases (functional and non-functional).
- **Output Format**: Jira format for the output test cases.
- **Tech Stack**: Node.js (Backend) with TypeScript, React (Frontend) with TypeScript.
- **LLM Integrations**: Ollama, LM Studio, Grok, OpenAI, Claude, Gemini.
- **Input Method**: User will copy/paste Jira requirements into a chat-like input interface.
